Wave 2: Add the Intellectual Contribution
Phase 4: Theoretical Framework (THE KEY DIFFERENTIATOR)
The problem: Zero formal analysis. This is the largest gap for ICML.
The plan — three formal results, each motivated by your empirical data:
Result 1: Quadratic Token Complexity for Agentic Loops
Motivation: Your data shows ReAct consumes 14× more tokens than Vanilla. Finding 03 claims "quadratic scratchpad growth" but it's never proven.
Theorem: Let an agentic RAG system execute $K$ iterations, where iteration $i$ produces $t_i$ tokens of reasoning and observation. The total token cost is:
$$T(K) = \sum_{k=1}^{K} \left(|q| + \sum_{i=1}^{k-1} t_i\right) = K|q| + \sum_{i=1}^{K-1}(K-i) \cdot t_i$$
For bounded step size $t_i \leq \bar{t}$, this gives $T(K) = O(K^2 \bar{t})$ — quadratic in iterations.
Corollary: The cost per unit accuracy gain increases superlinearly: if accuracy saturates at iteration $K^*$ but the loop continues to $K > K^*$, the marginal cost is $O(K \bar{t})$ per wasted iteration with zero accuracy gain.
Validation: Plot predicted $O(K^2)$ vs. actual token consumption from the ReAct iteration ablation (3/7/10). The fit should be tight.
Result 2: RLM Termination Analysis
Motivation: Your data shows 3.4% of RLM runs enter infinite loops. This is a formalizable pathology.
Definitions:
- A decomposition function $d: \mathcal{Q} \to \mathcal{P}(\mathcal{Q})$ maps a question to sub-questions
- The decomposition graph $G_d(q)$ has edges $q \to q'$ when $q' \in d(q)$
Theorem (Termination): RLM terminates for question $q$ if and only if $G_d(q)$ is a directed acyclic graph (DAG).
Corollary (Bounded recursion): With depth limit $D$ and max branching factor $b$, RLM always terminates in at most $\sum_{i=0}^{D} b^i = O(b^D)$ LLM calls.
Empirical connection: The 3.4% loop rate = $\Pr[G_d(q) \text{ contains a cycle}]$ under gpt-4o-mini. This varies by model — the cross-model loop rate becomes an interesting diagnostic.
Result 3: Retrieval Sufficiency Bound
Motivation: Your top-k ablation shows a sharp knee at top_k=10 for 2-hop questions. This is predictable.
Model: For a $k$-hop question, let $r_i$ be the retrieval rank of the $i$-th evidence document. Assume $r_i \sim \text{Geometric}(p)$ i.i.d. (each document at each rank has probability $p$ of being the correct evidence).
Theorem: The probability that Vanilla RAG retrieves all $k$ evidence documents in the top-$n$ results is:
$$P_{\text{succ}}(n, k) = \left(1 - (1-p)^n\right)^k$$
Corollary: For 2-hop questions ($k=2$), the accuracy gain from increasing top-$n$ from 5 to 10 is:
$$\Delta P = \left(1-(1-p)^{10}\right)^2 - \left(1-(1-p)^5\right)^2$$
Validation: Fit $p$ from the top_k=3 data point, predict the top_k=5/10/20 curve, compare to actual. If the fit is good, this is a predictive theoretical model for retrieval depth — novel and useful.
Paper structure: New §4 "Theoretical Analysis" with three subsections, each a theorem + proof + empirical validation. This transforms the paper from "empirical report" to "principled analysis with empirical validation."

Phase 9: Novel Diagnostic Metric — Prompt Sensitivity Coefficient
The idea: Formalize "prompt sensitivity" as a reusable metric that other researchers can compute for their architectures.
Definition: The Prompt Sensitivity Coefficient (PSC) of an architecture $\mathcal{A}$ is:
$$\text{PSC}(\mathcal{A}) = \frac{\max_{v \in V} \text{EM}(v) - \min_{v \in V} \text{EM}(v)}{\text{EM}(\text{default})}$$
where $V$ is the set of prompt variants tested.
This gives you a novel contribution that others can adopt — IRCoT has PSC=0.19, ReAct has PSC=0.88, RLM has PSC=0.69. A reviewer can't say "just an engineering report" when you've introduced a new metric.
